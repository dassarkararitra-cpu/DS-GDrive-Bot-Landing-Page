# DS GDrive Bot Web Hub

This repository contains the official landing page and legal hub for **DS GDrive Bot**, a Telegram bot designed to stream and manage files directly to Google Drive. The site is a responsive, single-page application featuring a modern light/dark mode UI, built to satisfy Google API verification requirements.

## Features

* **Direct Streaming:** Information on how the bot bypasses device storage limits to stream remote files and Telegram media directly to Google Drive.
* **Quota Monitoring:** Highlights the `/driveinfo` command for users to instantly check their available Google Drive storage capacity.
* **Secure OAuth Auth:** Details the implementation of official Google OAuth 2.0 authentication to ensure user credentials remain private.
* **Integrated Legal Hub:** Dedicated sections for the Privacy Policy and Terms of Service, specifically outlining that user Google OAuth tokens are securely encrypted, used strictly for user-authorized transfers, and never shared with third parties.
* **Responsive Design:** Built with Tailwind CSS, ensuring a seamless experience across mobile, tablet, and desktop devices with automatic system theme detection (Dark/Light mode).

## Tech Stack

* **HTML5:** Semantic, accessible markup.
* **Tailwind CSS:** Utility-first CSS framework (loaded via CDN for zero-build-step deployment).

## Setup & Deployment

1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser to preview the site locally.
3. Deploy to any static hosting provider (e.g., GitHub Pages, Cloudflare Pages, Vercel, Netlify) by pushing the directory to your connected repository.
