App Functionality & API Usage

DS GDrive Bot is a Telegram automation tool that connects your Telegram chat directly to your personal Google Drive account. Below is a detailed breakdown of the user journey, the app's features, and exactly how we utilize the Google Drive API to provide these services.

1. OAuth Authentication

When a user sends the /start command in Telegram, the bot provides a unique, secure login link. Clicking this link directs the user to the official Google OAuth 2.0 consent screen.

Why we need API access: We request standard Google Drive scopes to allow the bot to act on the user's behalf. Without this, the bot cannot route files from Telegram into the user's private Drive storage.

2. Direct File Uploads

Once authenticated, the user can forward any Telegram document, video, or audio file directly to the bot. The bot intercepts this file and streams it directly to the user's connected Google Drive.

API Utilization: We use the Drive API's files.create method to write the incoming data stream into the user's designated Google Drive folder, bypassing the need for local device storage.

3. Link Cloning

If a user sends a public HTTP/HTTPS link or a shared Google Drive link to the bot, it will process the URL and automatically clone the target file into the user's Drive.

API Utilization: The bot uses the Drive API to initiate a server-side copy of the requested resource directly into the authenticated user's account for maximum speed.

4. Remote File Management

Users can send the /manage command in Telegram to browse their Drive folders, create new folders, delete files, or check their storage limits using /driveinfo.

API Utilization: We utilize the files.list, files.delete, and about.get API methods to provide a virtual Drive explorer interface directly inside the Telegram chat menu.
